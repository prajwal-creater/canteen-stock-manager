# Police Canteen Stock Manager

A comprehensive inventory and stock management system for police canteens with web admin dashboard and mobile app.

## Features

- ✅ Add/Edit/Delete canteen items
- ✅ Manage quantity and price for each item
- ✅ Real-time stock tracking
- ✅ Check item availability
- ✅ Admin dashboard (Web)
- ✅ Mobile app for checking inventory

## Project Structure

```
canteen-stock-manager/
├── backend/                 # Node.js/Express API
├── admin-dashboard/         # React web dashboard
├── mobile-app/             # React Native mobile app
└── README.md
```

## Tech Stack

### Backend
- Node.js
- Express.js
- MongoDB / PostgreSQL
- JWT Authentication

### Web Admin Dashboard
- React.js
- Redux (State Management)
- Axios (API calls)
- Material-UI / Tailwind CSS

### Mobile App
- React Native
- Redux / Context API
- React Navigation
- Axios
